# 《最后一矛》/ The Last Spear — Ch.1～Ch.4 完整垂直切片原型

红黑涂鸦风 HTML5 Canvas 动作原型。无构建，打开即可玩。**终章 Ch.4 蓝心开合已实装**，含结局 A/B。

## 如何打开

### 方式 A：本地静态服务器（推荐）

```bash
cd /workspace/infinite-spear
python3 -m http.server 8765
```

浏览器打开：http://127.0.0.1:8765/

### 方式 B：直接打开文件

用浏览器打开 `index.html`（`file://`）。部分浏览器对本地脚本无限制，一般可玩。

## 操作

| 动作 | 键盘 | 鼠标 |
|------|------|------|
| 移动 | `WASD` / 方向键 | — |

## 选章

- **标题屏**：左右或 `1`/`2`/`3`/`4` 选章，Enter / 点击出发。开发期 **各章可直接选**。
- **通关 Ch.1**：自动解锁 Ch.2；结算屏可进 **笑墙合拢**。
- **通关 Ch.2**：自动解锁 Ch.3；结算屏可进 **哨兵一锤**。
- **通关 Ch.3**：自动解锁 Ch.4；结算屏可进 **蓝心开合**。收编钉头则 `nailRecruited=true`，Ch.4 有钉头掩体。
- **通关 Ch.4**：终章结算（结局 A 或 B）；回营地。
- **失败**：R / Enter 重试当前章；T 回标题选章。

## 玩法目标

### Ch.1 矛阵起夜

1. 骑着「无限」在两座**红线塔卫**之间机动。
2. 躲开三种红点弹幕：点雨、短划扫射、爆点环形。
3. 用矛戳塔底座的 **+** / **×**，拆掉两座塔即通关。
4. 塔墙会缓缓合拢；间隙过窄会被夹死。
5. 冲刺后偶尔闪「遗忘」旁白。

### Ch.2 笑墙合拢（Boss：城魂·咧嘴）

1. 场景：右下**密线要塞**、+/× **塔墙夹击**、贴墙的**咧嘴圆脸**。
2. Boss 循环招式：怒视减速、齿刃扇射、笑墙夹击。
3. 先拆墙底 **+** / **×**（或等笑超过约 72%）让脸**可打**，再矛戳打脸。
4. 打空 Boss 血条即通关。

### Ch.3 哨兵一锤（精英：节触哨·钉头）

1. 场景：**中立节触哨区**、远方 **蓝心** 不定期**远光扫射**。
2. 钉头招式：触手卷、钉砸（落地留无弹安全区）。
3. **双结局**：
   - **收编**：蓝心扫射时靠近钉头并 **K 格挡**，或同站安全区 → 收编条满。`nailRecruited=true`，Ch.4 钉头掩体 ON。
   - **击败**：矛戳打空钉头血条 → Ch.4 无掩体。

### Ch.4 蓝心开合（终局 Boss：天裂之主·蓝心）

1. **拆荚**：四条肢体末端的**圆荚**会定时爆炸；矛戳拆掉圆荚，激活关节阴影。
2. **攀关节**：站在发光关节处积攒攀爬条；攀满后蓝心窗输出加倍。
3. **锁定**：蓝心开锁定射线并减速；若 Ch.3 已收编，**钉头掩体**会砸出安全区挡雨/挡射线。
4. **蓝心窗**：心张开时可矛戳输出；血空后进入终局选择。
5. **结局分支**（矛戳选边）：
   - **A 扎蓝心**：红雨暂停，无限吞掉烬矛的名字（无名骑手轮回）。
   - **B 扎「还要」**（推荐正史）：蓝心闭合，红雨变细，无限睡着，烬矛徒步回家。

## 已知限制

- Boss 脸（Ch.2）位置固定贴在要塞侧，不会随塔墙物理位移。
- 无音效；美术为程序化颤抖线，非手绘帧动画。
- 触屏未做虚拟摇杆（键鼠优先）。
- 「遗忘」成长兑换未实装，仅有冲刺旁白闪现。
- Ch.4 攀爬为站立积条抽象，非真实平台跳跃关。
