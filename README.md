红黑涂鸦风 HTML5 Canvas 动作原型。无构建，打开即可玩。**终章 Ch.4 蓝心开合已实装**，含结局 A/B。

## 操作

| 动作 | 键盘 | 鼠标 |
|------|------|------|
| 移动 | `WASD` / 方向键 | — |
| 矛戳 | `J` / `Z` | 左键 |
| 盾轮格挡 | `K` / `X` | 右键 |
| 无限冲刺 | `空格` / `L` / `C` | — |
| 选章 | `1`/`2`/`3`/`4` | 点击章节卡片 |
| 开始 | `Enter` / `空格` | 点击画布 |
