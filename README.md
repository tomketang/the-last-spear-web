## 玩法目标

### Ch.1 矛阵起夜
骑「无限」拆两座红线塔卫底座的 + / ×，躲开红雨弹幕。

### Ch.2 笑墙合拢（Boss：城魂·咧嘴）
拆墙后打脸；怒视减速、齿刃、笑墙夹击。

### Ch.3 哨兵一锤（精英：节触哨·钉头）
收编（蓝心扫射时 K 格挡）或击败钉头。

### Ch.4 蓝心开合（天裂之主·蓝心）
拆荚 → 攀关节 → 打蓝心窗；结局 A 扎蓝心 / B 扎「还要」（正史）。
